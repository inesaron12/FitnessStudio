# FitnessStudio 

A responsive, single-page website for a fitness studio built entirely with vanilla HTML5 and CSS3. This project demonstrates modern web layout techniques without the use of external CSS frameworks.

## Features
- **Class Schedule:** A clean, easy-to-read weekly timetable.
- **Trainer Bios:** Responsive profile cards introducing the studio's instructors.
- **Membership Tiers:** Tiered pricing cards highlighting different subscription options.

## Technical Implementation
This project strictly adheres to the assignment requirements:
- **Semantic HTML5:** Uses proper landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) and strict hierarchy (only one `<h1>`).
- **Modern CSS3:** Completely framework-free. Uses a global `box-sizing: border-box` reset and custom CSS variables (`:root`) for consistent color theming.
- **CSS Flexbox:** Utilized for the navigation bar, internal card alignment, and footer layout.
- **CSS Grid:** Utilized for the class schedule layout and the responsive grid system for the trainer and pricing cards.
- **Responsive Design:** Fully mobile-responsive across phone, tablet, and desktop viewports with zero horizontal scrolling. 

## How to Run
Since this project uses no build tools or frameworks, simply clone the repository and open `index.html` in your preferred web browser.
